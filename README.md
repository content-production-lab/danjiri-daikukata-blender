# だんじり 大工方（Blender版）

![木造の地車の屋根から大工方が団扇で合図し、曳き手が町家の角を回り込む宣伝イラスト](promo/github-cover.jpg)

カバー画像はCodexの内蔵画像生成機能で制作したAI生成イラストです。

地車（だんじり）の大屋根に立つ大工方（だいくがた）になって、団扇の合図で曳き手と梃子方を動かし、町の角で「やりまわし」を決める3Dブラウザゲームです。地車・人・町並みは Blender の Python スクリプトで作っています。

公開URL: https://content-production-lab.github.io/danjiri-daikukata-blender/

仕様は [docs/SPEC.md](docs/SPEC.md) を参照してください。

## 遊び方

スマホは「かんたん操作」が標準です。「発進 / 再開」を1回タップすると進み続け、左右の団扇だけを操作します。「停止」も1タップ。速さと重心は自動補助されるため、同時押しは不要です。跳ぶ操作は使いません。操作方式はタイトルで選択・保存できます。

タイトルで「チュートリアル」「通常ステージ」を別々に選びます。チュートリアルは240m・右左2角の専用コースで、発進・停止・右折・左折を練習します。最初の団扇と「戻せ」では入力を待って進行を止め、失敗時は練習だけやり直せます。途中でもタイトルへ戻れます。完了後は通常ステージへ進むか、タイトルへ戻るかを選べます。

通常ステージは独立した760m・7角のコースです。先頭から開始し、再挑戦でも練習を挟みません。練習の時間・得点・傷みは持ち越しません。

PCの標準「手動操作」では、次のキー・ボタンを使います。

| 操作 | キー | 画面のボタン |
| --- | --- | --- |
| 曳け／止め | W/↑・S/↓ | 左下 |
| 団扇の合図（後梃子で曲げる） | A / D | 左下 |
| 体重移動 | ← / → | 右下 |
| 跳ぶ | Space | 右下 |
| 視点／音／一時停止 | C / M / P | 右上（音・一時停止） |

難易度は「やさしい」「ふつう」「本職」から選べます。角が近づくと「団扇！」「戻せ！」の合図が出て、振る向きのボタンが光ります。

手動操作のタッチ入力は指ごとに管理します。指を離す・操作をキャンセルする・画面を離れると入力を解除し、画面を離れた場合は一時停止します。横持ちがおすすめです。結果画面とXの投稿文には難易度・操作方式を表示します。

## 開発

```bash
npm install
npm run dev
npm run check
```

`npm run check` は lint・型チェック・テスト・ビルドをまとめて実行します。

### モデルを作り直す

Blender 5.2 で、プロジェクト直下から実行します。`public/models/*.glb` と `public/og.png` が書き出されます（`-- --no-og` で OGP 画像を省略）。

```bash
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup -P blender/build_all.py
```

| パス | 内容 |
| --- | --- |
| `blender/build_all.py` | 地車・人・町並みの生成と OGP 画像のレンダリング |
| `src/sim/` | 挙動計算と採点（描画に依存しない。vitest でテスト） |
| `src/render/` | three.js による描画（`.glb` の読み込み、群衆、町並み） |
| `src/audio.ts` | 鳴物と環境音（WebAudio で合成。音声ファイルなし） |
| `src/share.ts` | X の投稿画面の URL（API は使わない） |
| `blender/overlay_caption.py` | 画像に宣伝用の文字を重ねる（`tl`／`tr` で位置を指定） |
| `blender/render_promo.py` | X 宣伝用の画像 `promo/x-post.png`（1200×675）のレンダリング |

外部の画像・3D・音の素材は使っていません。

`promo/x-post-ai.png` の絵は **AI生成（Codex の内蔵画像生成、2026-10-12）** です。依頼文は `promo/codex/prompt.md`、採用した原画は `promo/codex/codex-2.png`。文字は `blender/overlay_caption.py` で重ねています。ゲーム本体には使っていません。OGP 画像の題字は BIZ UD明朝（SIL Open Font License）でレンダリングしています。
