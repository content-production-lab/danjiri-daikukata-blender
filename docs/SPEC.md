## 1. 目的

地車（だんじり）の大屋根に立つ大工方の視点で、やりまわしを決める3Dブラウザゲーム。既存版の挙動計算を引き継ぎ、見た目を Blender 製のモデルに置き換え、クリア後に X へ結果を投稿できるようにする。スマホでも遊べること。

## 4. モデル（Blender）

| モデル | 内容 |
| --- | --- |
| 地車 | 唐破風の大屋根・小屋根、鬼板、高欄、彫物（簡略化した立体）、車輪、提灯、綱の付け根。前方 = +x |

- 合計 8MB 以下（実績: `.glb` 3つで約2MB、OGP 画像込みで約2.9MB）。三角形数の実績は地車 約2.8万、人 1体 約700（見物人用 200）。
- 材質は名前で three.js 側のテクスチャ付き材質に対応させる。彫物の凹凸の陰影は頂点色に焼き込む。
- 大工方の相方は大屋根の後ろ寄りに立たせる（一人称の視界をふさがない）。

## 5. ゲーム

- チュートリアル（操作練習コース240m・右左2角）と、通常ステージ（浜町曳行コース760m・7角）を独立させる。タイトルの別ボタンから開始し、通常ステージは先頭から始める（2026-10-13 改訂仕様をチャット承認）。
- 操作: 曳け（W/↑）、止め（S/↓）、団扇の合図（A/D）、体重移動（←/→）、跳ぶ（Space）、視点・音・一時停止（C/M/P）。
- 終了条件: 宮入り（クリア）、転落、横転、傷み100で曳行中止。

### 5.0 難易度と手がかり（2026-10-12 追加）

タイトル画面で選ぶ。選んだ難易度はブラウザに保存する。数値は `src/sim/guide.ts`。

| | やさしい | ふつう（既定） | 本職 |
| --- | --- | --- | --- |
| 体重移動 | 全自動 | 75% 自動 | 手助けなし |
| 団扇（後梃子） | 通りに沿う合図を 80% 足す | 手助けなし | 手助けなし |
| 速さ | 角の手前で目安を超えたら自動で減速 | 手助けなし | 手助けなし |
| 傷み | 半分 | そのまま | そのまま |

- 手がかり（全難易度）: 角が近づくと上部に「団扇！」（角の向きへ振る）、角を過ぎたら「戻せ！」（逆へ振って回りすぎを止める）を点滅表示し、振る向きの団扇ボタンを光らせる。振りはじめは角の手前 6m＋速さ[m/s]×0.4m。
- 角まで 35m 以内では速さの数字を色分けする（目安以内は緑、+5km/h までは黄、それ以上は赤）。目安は角で 18km/h、角から 1m 離れるごとに +0.9km/h。
- ランクの境目は難易度によらず共通。結果画面と X の投稿文に難易度を添える。
- 合格条件（テスト）: やさしいは曳けを押し続けるだけで宮入りできる。ふつうは手がかりどおりに操作すれば無傷で宮入りでき、曳けを押すだけでは宮入りできない。

### 5.0a 操作方式・練習（2026-10-13 チャット承認）

- スマホの初期値は「かんたん操作」、PCは「手動操作」。明示選択を保存し、再訪時は保存値を優先する。
- かんたん操作: 発進／停止／再開は1タップで状態を保持。団扇だけ押し、合図が消えたら離す。全難易度で重心は全自動、角の速度を自動調整し直線は26km/hを上限の目安とする。団扇補助・傷み倍率は選択した難易度を使う。重心ボタン・跳ぶ操作は使わない。
- 手動操作: 従来のキー・ゲームパッド・タッチ操作を維持。指をpointerIdごとに管理し、1本の解除で別の指の入力を解除しない。pointercancel・lostpointercaptureでも解除する。
- 一時停止・画面の非表示・フォーカス喪失・再挑戦・練習切替では入力と発進保持を解除。復帰時に勝手に走り出さない。
- 練習: 発進→停止→再開→右折→左折。練習中だけは全方式で重心・速度を補助（直線の目安22km/h）、団扇は自分で操作。右折・左折の最初の団扇と戻せで進行を止め、適切な方向の入力を待つ。失敗は練習のやり直し画面へ送る。
- 練習は専用コースの宮入りで完了し、進行を止める。終了後は「通常ステージへ」または「タイトルへ戻る」を選ぶ。練習途中・失敗時もタイトルへ戻れる。通常ステージへの自動移動や練習の前置きは行わない。通常の再挑戦も通常コースの先頭から開始する。採点帳簿・時間・傷み・連続数・乱数状態は通常ステージ開始時に初期化する。
- 切替時は選んだコースの町並み・宮・コース図へ更新する。同じコースの再挑戦では町並みを再生成せず、別コースへの切替では古い町並み固有の描画資源を解放し、共有するBlender部品・材質を維持する。
- 角の合図は従来の距離による予告に加え、曲がる最中の向きと回転速度から補正する（角の手前の合図距離から通過後14mまで）。単に一定距離で振り続けさせず、戻せと手を離すタイミングを案内する。
- 結果・X投稿には難易度と操作方式を表示し、角の完了数は本編7角で数える。操作方式間の得点を同条件の記録とは扱わない。

### 5.1 スコア

角ごと（角の手前16m〜通過後14m）と、曳行全体で集計する。

| 種別 | 項目 | 点 |
| --- | --- | --- |
| 加点 | 角の速さ | 最低速度[km/h]×25 ＋ 平均速度×12 |
| 加点 | 無傷 | 角で接触なし +400 |
| 加点 | 際（きわ） | 接触なしで家並みとの最小間隔が 0.3m 未満 +300、0.6m 未満 +200、1.0m 未満 +100 |
| 加点 | 大技 | 角の最中に跳んで無事に着地 1回につき 150＋平均速度×12 |
| 加点 | 片輪返し | 角で片輪が浮き、接触・横転なしで戻す +200 |
| 倍率 | 連続 | 無傷の角が続くと角の加点に ×(1＋0.1×(連続数−1))、上限 ×1.5 |
| 加点 | タイム | 宮入りで (150×本編距離/650 − 本編秒数)×20、四捨五入（0未満は0）。現コースの本編距離は760m |
| 加点 | 無事 | 宮入りで (100 − 傷み)×5 |
| 減点 | 接触 | 速さ[m/s]×40（電柱 ×1.5、布団 ×0.5） |
| 減点 | ドスン | 浮いた車輪が落ちた衝撃×60 |
| 減点 | 体勢の崩れ | 重心が危険域（±0.75超）にいた 1秒につき 40 |
| 減点 | 止まりかけ | 角の最低速度が 5km/h 未満 −200 |

### 5.3 X 投稿

- 結果画面に「X にポスト」ボタン。X の投稿画面（`https://x.com/intent/post`）を開き、タイム・スコア・総合ランク・URL・`#だんじり大工方` を入れる。API は使わない。
- 本編の失敗（転落・横転・曳行中止）でもボタンを出す。文面は失敗用で、失敗の種類と理由、曲がり終えた角の数（例: 2/7 の角まで）を入れる。練習中の失敗では結果投稿へ進めない。
- リンクのカード表示用に OGP（`og:image` 1200×630、`twitter:card` = `summary_large_image`）を付ける。

### 5.4 操作表示とスマホ

- 画面の左右の端に操作を常に表示する。左: 団扇（左・右）、曳け・止め。右: 体重移動、跳ぶ。キーを押している間は光らせる。
- スマホはかんたん操作を標準とし、左に左右の団扇、右に発進／停止／再開を配置する。同時押しは不要。手動操作を選べば従来配置のタッチボタンを使える。
- スマホでは影の解像度と描画解像度を下げる。横持ちを推奨（縦持ちでも遊べる）。
