- 版: v0.1（2026-10-12、実装に合わせて数値を更新）

## 1. 目的

地車（だんじり）の大屋根に立つ大工方の視点で、やりまわしを決める3Dブラウザゲーム。既存版の挙動計算を引き継ぎ、見た目を Blender 製のモデルに置き換え、クリア後に X へ結果を投稿できるようにする。スマホでも遊べること。

## 3. 構成

## 4. モデル（Blender）

| モデル | 内容 |
| --- | --- |
| 地車 | 唐破風の大屋根・小屋根、鬼板、高欄、彫物（簡略化した立体）、車輪、提灯、綱の付け根。前方 = +x |
| 人 | 法被・鉢巻・股引。走りの姿勢4つ＋立ち姿勢、見物人用の簡易な立ち姿勢。姿勢を切り替えて走らせる |
| 町 | 町家3〜4種、電柱、鳥居、社殿 |

- 合計 8MB 以下（実績: `.glb` 3つで約2MB、OGP 画像込みで約2.9MB）。三角形数の実績は地車 約2.8万、人 1体 約700（見物人用 200）。
- 材質は名前で three.js 側のテクスチャ付き材質に対応させる。彫物の凹凸の陰影は頂点色に焼き込む。
- 大工方の相方は大屋根の後ろ寄りに立たせる（一人称の視界をふさがない）。

## 5. ゲーム

- 1面のみ（浜町曳行コース、角5つ）。
- 操作: 曳け（W/↑）、止め（S/↓）、団扇の合図（A/D）、体重移動（←/→）、跳ぶ（Space）、視点・音・一時停止（C/M/P）。
- 終了条件: 宮入り（クリア）、転落、横転、傷み100で曳行中止。

### 5.1 スコア

角ごと（角の手前16m〜通過後14m）と、曳行全体で集計する。

| 種別 | 項目 | 点 |
| --- | --- | --- |
| 加点 | 角の速さ | 最低速度[km/h]×25 ＋ 平均速度×12 |
| 加点 | 無傷 | 角で接触なし +400 |
| 加点 | 際（きわ） | 接触なしで家並みとの最小間隔が 0.3m 未満 +300、0.6m 未満 +200、1.0m 未満 +100 |
| 加点 | 大技 | 角の最中に跳んで無事に着地 1回につき 150＋平均速度×12 |
| 加点 | 片輪返し | 角で片輪が浮き、接触・横転なしで戻す +200 |
| 倍率 | 連続 | 無傷の角が続くと角の加点に ×(1＋0.1×(連続数−1))、上限 ×1.5 |
| 加点 | タイム | 宮入りで (150 − 秒)×20（0未満は0） |
| 加点 | 無事 | 宮入りで (100 − 傷み)×5 |
| 減点 | 接触 | 速さ[m/s]×40（電柱 ×1.5、布団 ×0.5） |
| 減点 | ドスン | 浮いた車輪が落ちた衝撃×60 |
| 減点 | 体勢の崩れ | 重心が危険域（±0.75超）にいた 1秒につき 40 |
| 減点 | 止まりかけ | 角の最低速度が 5km/h 未満 −200 |

### 5.2 総合ランク

宮入り時の合計スコアで決める。境目は自動操縦の試走結果（慎重 約6,300、普通 約8,000、角で跳ぶ 約10,400）から決め、`src/sim/score.ts` に置く。宮入りしなければ D。

| ランク | 呼び名 |
| --- | --- |
| S | 極（11,000 以上） |
| A | 見事（8,800 以上） |
| B | ええで（7,000 以上） |
| C | まだまだ（4,800 以上） |
| D | 出直し（それ未満） |

### 5.3 X 投稿

- 結果画面に「X にポスト」ボタン。X の投稿画面（`https://x.com/intent/post`）を開き、タイム・スコア・総合ランク・URL・`#だんじり大工方` を入れる。API は使わない。
- 失敗（転落・横転・曳行中止）でもボタンを出す。文面は失敗用で、失敗の種類と理由、曲がり終えた角の数（例: 2/5 の角まで）を入れる（2026-10-12 追加）。
- リンクのカード表示用に OGP（`og:image` 1200×630、`twitter:card` = `summary_large_image`）を付ける。

### 5.4 操作表示とスマホ

- 画面の左右の端に操作を常に表示する。左: 団扇（左・右）、曳け・止め。右: 体重移動、跳ぶ。キーを押している間は光らせる。
- スマホ（タッチ端末）では同じ位置がタッチボタンになる。マルチタッチで両手同時に押せる。
- スマホでは影の解像度と描画解像度を下げる。横持ちを推奨（縦持ちでも遊べる）。

## 6. 完了条件・検証

1. `npm run check`（lint・型チェック・テスト・ビルド）が通る。
2. 採点のテスト: 加点・減点・倍率・ランクが効く。自動操縦が完走する。
3. 内蔵ブラウザで PC 幅・スマホ幅を確認: モデル表示、1フレームの処理時間、読み込み量、X 投稿 URL の形式（実際には投稿しない）。
4. 公開 URL で起動する。

## 7. リスク・戻し方

- スクリプトで作るモデルなので、手で彫り込んだ精密さはない。
- 古いスマホでは重い可能性がある。
- 戻し方: リポジトリとフォルダを削除する（削除は事前に確認を取る）。
